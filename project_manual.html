flag_lookup.html 機能詳細
機能説明
手入力検索入力欄に国名を入力してEnterキーで表示。日本語・英語両対応。入力欄クリックで前の入力が自動クリア。
入力候補入力中に候補が表示される。日本語入力→日本語候補、英語入力→英語候補。
音声入力（日本語）🎤 日本語ボタン：日本語専用ループ認識。見つかるまで自動で繰り返す。
音声入力（英語）🎤 Englishボタン：英語専用ループ認識。見つかるまで自動で繰り返す。
国旗表示各国の正式縦横比でBOX表示。SVGはflag-iconsライブラリのもの（4:3固定）をpreserveAspectRatio="xMidYMid meet"で表示。
面積・人口国旗下に面積（km²・日本比）と人口を表示。データはCIA World Factbook / World Bank 2023年頃。
別名対応USA、英、米、Deutschland、Nipponなど多数の別名・略称に対応。中点「・」なしでも認識。
⚙️
技術的注意点
⚠️ flag-iconsのSVGについて：全国旗のSVGはviewBox="0 0 640 480"（4:3）で統一されており、描画内容も4:3座標系で描かれている。viewBoxを変更すると国旗の一部が切れるため、preserveAspectRatio="xMidYMid meet"でBOX内に収める方式を採用。BOXサイズを各国の正式比率に設定することで縦横比を表現している。
🎤 音声認識について：Web Speech APIはHTTPS環境でのみ動作（file://不可）。ChromeとSafariで動作、Firefoxは非対応。音声認識はループモードで動作し、国旗が見つかるまで自動で繰り返す。入力欄クリックや別ボタン押下で停止。
📦 使用ライブラリ：flag-icons v7.2.3（SVGデータをHTMLに直接埋め込み済み。外部CDN不使用・オフライン動作）。Excelファイル生成にはopenpyxl・cairosvgを使用。
データ内容
対応国数197か国（国連加盟194 + パレスチナ・コソボ・台湾）
人口データ実数（人）で格納。バチカン約800人、ナウル約1万人など
面積データkm²。日本基準値 = 377,975 km²
出典CIA World Factbook / World Bank (2023年頃)
